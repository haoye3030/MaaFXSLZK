# 待完成功能清单

本文档记录 MaaFXSLZK 计划实现但尚未完成的功能。

## 风险分级说明

| 标记 | 含义 | 实现约束 |
|---|---|---|
| 🟢 | 无消耗，纯粹点击 | 可直接实现 |
| 🟡 | 有消耗或状态不可逆 | 需用户确认；必须做消耗前后校验 |
| 🔴 | 涉及抽卡/付费/资源损失 | **默认禁点**，需显式 opt-in |
| ⚙️ | 需要额外配置项 | 涉及 `option` 字段（如下拉框、输入框） |

## 优先级说明

| 级别 | 含义 |
|---|---|
| ⭐⭐⭐ | 每日必做、收益高、素材现成 |
| ⭐⭐ | 每日/每周可做，收益中等 |
| ⭐ | 周期性或可选 |

## 六、关卡与战斗

### 11. 自动托管主线关卡（每章第 5 / 10 关） ⭐⭐ 🟡 ✅ 已实现并实机验证

| 项 | 内容 |
|---|---|
| 入口 | 主界面右下「出击 ATTACK」(1182,572) → 左侧「主线」→ 关卡地图 |
| 逻辑 | 章节下拉选目标章 → 切难度 → OCR 定位「X-5」或「X-10」→ 点圆形关卡按钮 → 详情面板点「托管」→ 托管设置强制「重复关卡次数=1次」→ 开始托管 → 等「停止托管」提示 → 确定 → 关面板 → 结算 → 领取 → 离开 → 返回主界面 |
| 关键坐标 | 出击 (1182,572)；章节下拉 (607,36)；章节列表 ROI [515,71,140,370]；简单 (963,607) / 困难 (1117,607)；托管 (830,585)；重复次数「1次」(137,136)；开始托管 (1072,620)；停止提示「确定」(838,461)；托管面板关闭 X (1141,18)；奖励「点击继续」(616,607)；结算「离开」ROI [550,555,730,155] |
| 风险 | 🟡 **消耗燃料**（1-5 实测 255），出战不可撤销 |
| 难点 | ① 托管设置默认是「重复关卡次数＝直到无法战斗」，必须强制改为 1 次，否则会一直刷到没燃料；② 单屏只显示 4 个关卡，需横向滚动查找；③ 结算页按钮数量会变（有/无「下一关」导致整体位移），OCR 的 ROI 必须放宽；④ 章节列表 20 项需分段滚动 |
| 已验证 | 章节切换、地图滚动找关卡（Stage1 超时后 Stage2 命中 1-10）、托管开战、战斗结算、收尾段（关闭面板→奖励→离开→回主界面）均单独跑通 |
| 完整跑通 | 主界面→出击→第一章→简单→定位 1-5→托管(1次)→战斗→结算→回主界面，全程 **64.8s succeeded**，燃料 25635→25380 |
| 可复用 | 同一套「出击→主线→托管」骨架可直接支撑 #13 竞技、#14 档案（换左侧分类与查找节点即可） |

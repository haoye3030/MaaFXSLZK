# 待完成功能清单

本文档记录 MaaFXSLZK 计划实现但尚未完成的功能。

## 风险分级说明

| 标记 | 含义 | 实现约束 |
|---|---|---|
| 🟢 | 无消耗，纯粹点击 | 可直接实现 |
| 🟡 | 有消耗或状态不可逆 | 需用户确认；必须做消耗前后校验 |
| 🔴 | 涉及抽卡/付费/资源损失 | **默认禁点**，需显式 opt-in |
| ⚙️ | 需要额外配置项 | 涉及 `option` 字段（如下拉框、输入框） |

## 优先级说明

| 级别 | 含义 |
|---|---|
| ⭐⭐⭐ | 每日必做、收益高、素材现成 |
| ⭐⭐ | 每日/每周可做，收益中等 |
| ⭐ | 周期性或可选 |

## 一、邮件与商店

### 1. 自动领取快过期邮件（剩余天数可配置） ⚙️ 🟢

| 项 | 内容 |
|---|---|
| 入口 | 主界面左上角邮件图标（`common/btn_mail.png`，ROI [15,154,30,32]） |
| 逻辑 | 进入邮箱 → 遍历邮件 → 按「剩余有效期」排序 → 领取剩余天数 ≤ 阈值的邮件 |
| 配置 | 新增 option：剩余天数阈值（默认 3 天） |
| 难点 | 需识别邮件列表里的剩余时间文本，建议用 OCR（项目已内置 zh_cn 模型） |
| 备注 | 「快过期」通常带特殊标记（红色角标/高亮），可作为辅助判据 |

### 2. 自动刷新购买贸易商店，补给兑换中的商品 🟡

| 项 | 内容 |
|---|---|
| 入口 | 港口/贸易商店页（待确认具体路径） |
| 逻辑 | 进入补给兑换 → 找到可兑换商品 → 用特定货币兑换 → 刷新商店（消耗钻石） |
| 风险 | ⚠️ **刷新商店消耗钻石**，需做「刷新前记录钻石数 → 刷新后校验」的消耗上限；建议设置每日最大刷新次数 |
| 难点 | 兑换货币类型多样（银币/钻石/道具），需按配置选择只兑换指定货币的商品 |
| 备注 | 用户需明确兑换策略（如只兑换银币商品、每日最多刷 3 次） |
